Introduction aux Permissions Linux

Qu'est-ce que les permissions Linux ?

Sous Linux, chaque fichier et dossier possède des permissions qui déterminent qui peut le lire, le modifier ou l'exécuter. Ce système de sécurité protège les données contre les accès non autorisés.

Comment voir les permissions ?

user@linux:~$ ls -l fichier.txt
-rw-r--r-- 1 user group 1234 Oct 7 10:30 fichier.txt
└──┬──┘ └┬┘ └┬┘ └┬┘
    │     │    │    └── Propriétaire
    │     │    └── Groupe
    │     └── Autres
    └── Type de fichier (- = fichier, d = dossier)

Les 3 Catégories (U/G/O)

  • User (u) - Le propriétaire du fichier
  • Group (g) - Le groupe associé
  • Others (o) - Tous les autres utilisateurs

Les 3 Droits (r/w/x)

  • Read (r) = 4 → Lire
  • Write (w) = 2 → Écrire
  • Execute (x) = 1 → Exécuter

Les 3 Catégories d'Utilisateurs

Principe : Chaque fichier Linux est associé à 3 catégories d'utilisateurs qui ont des droits différents.

User (Owner)

u

La personne qui a créé le fichier. Elle a le contrôle total sur son fichier.

Group

g

Les utilisateurs appartenant à un groupe partagé (ex: "developers").

Others

o

Tous les autres utilisateurs du système.

Exemple concret

Si Ahmed crée un fichier rapport.txt dans le groupe etudiants :

  • User (Ahmed) → Le propriétaire
  • Group (etudiants) → Tous les étudiants
  • Others → Tous les autres utilisateurs du système

Les 3 Droits de Base

Principe : Chaque droit a une valeur numérique qui correspond à une puissance de 2.
r

Read (Lecture)

= 4

Fichier : Voir le contenu
Dossier : Lister les fichiers

w

Write (Écriture)

= 2

Fichier : Modifier le contenu
Dossier : Ajouter/supprimer des fichiers

x

Execute (Exécution)

= 1

Fichier : Exécuter comme programme
Dossier : Entrer dans le dossier (cd)

La Règle d'Or

Valeur d'une catégorie = r + w + x

r = 4 + w = 2 + x = 1 = Maximum 7

Exemple de calcul

Pour le propriétaire avec les droits rwx :

r(4) + w(2) + x(1) = 7

Pour le groupe avec les droits r-x :

r(4) + -(0) + x(1) = 5

Tableau Synthétique de Référence

Ce tableau résume toutes les combinaisons possibles (0 à 7) pour une catégorie.
Octal Binaire Somme Symbolique Description
0 000 0+0+0 --- Aucun droit
1 001 0+0+1 --x Exécution seule
2 010 0+2+0 -w- Écriture seule
3 011 0+2+1 -wx Écriture + Exécution
4 100 4+0+0 r-- Lecture seule
5 101 4+0+1 r-x Lecture + Exécution (Standard dossier)
6 110 4+2+0 rw- Lecture + Écriture (Standard fichier)
7 111 4+2+1 rwx Tous les droits

Exemples courants

  • chmod 755 → rwxr-xr-x → Script/dossier public
  • chmod 644 → rw- r-- r-- → Fichier texte standard
  • chmod 700 → rwx------ → Dossier privé
  • chmod 777 → rwxrwxrwx → Tous les droits à tous (dangereux !)

Les Codes Impossibles

Pourquoi certains codes sont IMPOSSIBLES ?

Linux utilise la base octale (base 8). Les seuls chiffres valides sont : 0, 1, 2, 3, 4, 5, 6, 7

La valeur maximale = 4 + 2 + 1 = 7

Les chiffres 8 et 9 n'existent pas en octal !

Analyse du code 781

7
Valide
4+2+1 = rwx
8
IMPOSSIBLE
8 n'existe pas en octal
1
Valide
0+0+1 = --x
user@linux:~$ chmod 781 fichier.txt
chmod: mode invalide: '781'

Détectez les codes invalides !

Testez vous-même : Entrez un code à 3 chiffres pour vérifier s'il est valide.
